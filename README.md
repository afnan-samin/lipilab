## 💡 What is LipiLab?

There are two kinds of Bangla text on computers: **Unicode** (used on the web, Facebook, WhatsApp, mobile keyboards) and **Bijoy** (used in old Word files, government documents, newspapers, printing presses). Moving text from one to the other normally produces garbage.

**LipiLab fixes that in one click.** Paste or upload, convert, copy or download. Your text never leaves your device.

The special part is **Word files**: upload a `.docx` and download it back with the same layout — **bold stays bold, tables stay tables, columns stay columns.**

## ✨ Features

- **Both directions** — Unicode → Bijoy and Bijoy → Unicode, with Auto-detect.
- **Live mode** — output updates as you type, or press **Convert** to do it yourself.
- **Word files** — upload a `.docx`, download the converted file with formatting intact (tables, bold, columns, headers and footers).
- **Download** as `.txt` or `.docx`.
- **Editor tools** — swap, undo/redo, paste, upload, clear, copy, live word count, three font sizes.
- **Dark mode**, **keyboard shortcuts** (`?` to see them all).
- **Features board** — shows what the site can do, in **বাংলা or English**.
- **Private** — everything runs in your browser; nothing is uploaded. Free forever, no account needed.

## ⌨ Keyboard Shortcuts

| Keys | Action |
|---|---|
| `Ctrl` + `Enter` | Convert |
| `Ctrl` + `L` | Toggle Live mode |
| `Ctrl` + `Shift` + `C` | Clear input |
| `Ctrl` + `Shift` + `S` | Swap input / output |
| `Ctrl` + `C` | Copy output (while the output pane is focused) |
| `Ctrl` + `S` | Download as `.txt` |
| `Ctrl` + `D` | Toggle dark mode |
| `?` | Open the shortcuts panel |
| `Esc` | Close the open panel |
